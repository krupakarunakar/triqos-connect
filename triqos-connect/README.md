# TRIQOS Connect landing page

A responsive, single-page contact hub for TRIQOS International Institute. Designed with a royal-blue and gold palette.

- Phone: +91 97262 06767

- Instagram, Facebook and LinkedIn
- YouTube is intentionally omitted until the official channel URL is supplied.

## Add the official logo
1. Obtain the original, approved TRIQOS logo file (preferably transparent PNG or SVG).
2. Rename the file to `triqos-logo.png`.
3. Put it inside the `assets` folder, replacing the placeholder instructions.
4. Do not recreate or redraw the official logo.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `triqos-connect`.
2. Upload `index.html`, `styles.css`, and the complete `assets` folder from this package.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main`, folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish. The default address will be:
   `https://YOUR-GITHUB-USERNAME.github.io/triqos-connect/`
7. Open the published page on a phone and test every link.

## Create the final QR code
Only generate/print the QR after the GitHub Pages URL is live and tested. Encode the full published URL, including the trailing slash. This ensures the QR opens the landing page rather than a local file.

## Optional custom domain
If TRIQOS later wants `connect.triqos.com`, the owner of the `triqos.com` domain must add the DNS records requested by GitHub Pages and configure the custom domain in repository Settings → Pages. This is optional; the free `github.io` address works without domain changes.
